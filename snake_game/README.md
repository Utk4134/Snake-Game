# Simple Snake Game

A classic Snake game built using Python's built-in `turtle` graphics library. It requires zero external installations and is ready to play immediately!

## Prerequisites

- Python 3.x installed on your computer. (If you don't have it, download from [python.org](https://www.python.org/))

## How to Play

### Controls
- **W** or **Up Arrow**: Move Up
- **S** or **Down Arrow**: Move Down
- **A** or **Left Arrow**: Move Left
- **D** or **Right Arrow**: Move Right

### Goal
- Eat the red food to grow your snake and increase your score.
- Avoid hitting the screen borders or your own tail, as that will reset the game and clear your current score.

## How to Run

1. Open a terminal (Command Prompt or PowerShell).
2. Navigate to the folder containing the game:
   ```bash
   cd "D:\Gemini Course\snake_game"
   ```
3. Run the Python script:
   ```bash
   python snake.py
   ```
   *(Note: Depending on your Python installation, you might need to use `python3 snake.py`)*
